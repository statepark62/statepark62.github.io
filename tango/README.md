# 🧩 일본어 단어 놀이터

초급 일본어 학습자를 위한 단어 학습 웹앱(PWA)입니다. 카드로 익히고, 퍼즐로 풀고, 말로 써먹고, 글자를 직접 써 봅니다.
서버 없이 GitHub Pages에서 동작하며, 단어 데이터는 구글 시트에서 불러옵니다.

- 주소: https://statepark62.github.io/tango/
- 안내문·QR 코드: `notice.html`

## 기능

| 탭 | 내용 |
|---|---|
| 단어 카드 | 단어 · 뜻 · 정중형 · 한글 발음 · 예문. 카드/목록 보기, "알아요/아직이에요" 표시, 모르는 단어만 모아 보기, 음성 듣기 |
| 낱말퍼즐 | 학습 단어로 만든 가로세로 퍼즐. 판 크기, 작은 글자(ゃゅょっ) 포함 여부, 가타카나 포함 여부, 화면 자판 선택 |
| 말하기 | 질문에 일본어로 답하는 연습(질문 탭 데이터 사용). 문법·문화 한마디 |
| 글자쓰기 | 히라가나·가타카나를 행별로 골라 쓰기 연습. 탁음·반탁음·요음 지원, 획순 애니메이션과 따라 쓰기 |

공통 기능
- **범위 선택**: 전체 / 레벨(기본·N5·N4) / 4주 계획 회차 / 주제 회차
- **의견 보내기**: 화면 위 링크에서 의견을 보내면 시트에 쌓이고 메일로 알림이 옵니다.
- 오프라인에서도 열립니다(처음 한 번 접속한 뒤).
- 학습 기록(알아요 표시 등)은 각자 기기의 브라우저에만 저장됩니다.

## 파일 구성

배포 폴더(`tango/`)에 올리는 파일은 다음과 같습니다.

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체(스타일·스크립트·내장 데이터 포함, 한 파일) |
| `notice.html` | 카페용 안내문과 QR 코드 |
| `manifest.webmanifest` | 홈 화면에 설치할 때 쓰는 앱 정보 |
| `sw.js` | 오프라인용 서비스 워커 |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |

## 데이터: 구글 시트

앱은 구글 시트의 다음 탭을 읽습니다. 시트는 **"링크가 있는 모든 사용자: 뷰어"** 로 공유되어 있어야 합니다. 시트를 읽지 못하면 앱에 내장된 데이터로 동작합니다.

### `단어` 탭 (13개 열)

| 열 | 내용 |
|---|---|
| 단어 | 표제어. 히라가나, 외래어는 가타카나, な형용사는 `しずか(な)`처럼 표기 |
| 읽기(퍼즐용) | 퍼즐에 쓰는 읽기. 히라가나 또는 가타카나만 |
| 품사 | 동사 / い형용사 / な형용사 / 명사 / 시간·부사 중 하나 |
| 뜻 | 한국어 뜻 |
| 한자 | 한자 표기(없으면 비움) |
| 정중형 | 예: `たべます`, `あまいです`. 부사·인사말은 `(です 없음)` |
| 한글발음 | 정중형의 한글 발음 |
| 예문 / 예문 뜻 | 띄어쓰기한 히라가나 예문과 한국어 번역 |
| 메모 | 학습 팁(없으면 비움) |
| 4주 회차 | 숫자 1~8. 비우면 회차 범위에는 나오지 않음 |
| 주제 회차 | 숫자. 비우면 회차 범위에는 나오지 않음 |
| 레벨 | `N5` 또는 `N4`. **비우면 "기본(수업 단어)"** 으로 처리 |

단어 · 뜻 · 품사 · 읽기가 비어 있는 행은 무시됩니다. 단어(표제어)는 겹치지 않게 하세요. "알아요" 표시가 표제어 기준으로 저장되기 때문입니다.

### 다른 탭

- `질문`: 말하기 탭의 질문. 열은 품사, 라운드, 질문(한국어), 힌트, 정답 1~3, 한마디 구분(문법/문화), 한마디 내용
- `설정`: 회차 이름. 열은 종류(라운드/4주/주제), 번호, 이름, 설명
- `안내`: 안내 문구

### 단어 추가 방법

1. 단어를 `단어` 탭의 마지막 행 다음에 붙여넣습니다.
2. 앱을 새로고침하면 반영됩니다. 앱 파일을 다시 올릴 필요는 없습니다.

## 접속 기록과 의견 (구글 Apps Script)

- 방문과 의견은 별도의 Apps Script 웹앱으로 전송되어 시트(`접속기록`, `의견`)에 기록됩니다.
- 개인 이름은 받지 않으며, 기기별 임의 번호만 기록합니다.
- 전송에는 공유 토큰과 요청 횟수 제한을 둡니다. 스크립트를 수정하면 **배포 관리 → 새 버전**으로 다시 배포해야 합니다(주소는 그대로).
- 스프레드시트의 시간대를 서울로 설정해야 기록 시각이 맞게 보입니다.

## 배포 방법 (GitHub Pages)

1. 위 "파일 구성"의 파일을 `tango` 폴더에 올립니다.
2. 올린 뒤 화면 위쪽 작은 글씨의 **버전 표시**가 새 번호인지 확인합니다.
3. 예전 화면이 보이면 강력 새로고침(Ctrl+Shift+R)을 하거나 시크릿 창에서 열어 봅니다. 서비스 워커와 브라우저 캐시가 옛 파일을 보여 주는 경우가 있습니다.

## 시험하지 못한 것

개발 환경에서 구글에 접속할 수 없어 다음은 실제 환경에서 직접 확인이 필요합니다.
- 구글 시트에서 실제로 불러오는 동작
- Apps Script 기록과 메일 알림
- 실제 휴대폰·태블릿에서의 터치 글쓰기
- 홈 화면 설치와 오프라인 동작
