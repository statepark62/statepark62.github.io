# 매매 타이밍 대시보드

보유·관심 종목(미국/국내)의 PER, 배당수익률, 배당성향, 이동평균, RSI, (국내) 투자자별 수급을 매일 자동으로 수집하고,
조건에 맞으면 신호를 표시 + 이메일로 알려주는 개인용 투자 보조 도구입니다.
구글시트(데이터 저장·연산) + Apps Script(자동화) + 정적 웹페이지(한눈에 보기·한 달 차트) 조합으로 만들었습니다.

> ⚠️ 이 도구는 참고용 신호를 보여줄 뿐입니다. 실제 매수/매도 판단은 실적·뉴스 등을
> 직접 확인한 뒤 내려야 하며, 투자 손실에 대한 책임을 지지 않습니다.

---

## 1. 전체 구조

```
구글 스프레드시트 (1개 파일)
├── 시트: 매매타이밍        (미국 종목)
├── 시트: 국내매매타이밍     (국내 종목)
│
└── Apps Script (같은 프로젝트 안 여러 .gs 파일)
    ├── Code.gs       — 미국 시트 생성(setupSheet), 이메일 알림(sendAlertEmail), 공통 함수
    │                   ※ 안의 updateAllData(Alpha Vantage 방식)는 더 이상 쓰지 않음
    ├── 미국야후.gs    — 미국 종목 데이터 수집 (야후 차트 + 네이버 해외) ← 현재 사용
    ├── 국내종목.gs    — 국내 종목 데이터 수집 (네이버 금융 비공식 API, 투자자별 수급 포함)
    ├── 이력.gs        — 한 달치 일별 종가·수급 이력 (웹 대시보드 차트용)
    ├── 웹앱.gs        — 시트 + 이력을 JSON으로 내보내는 창구 (Web App 배포)
    └── 메뉴.gs        — 구글시트 메뉴에 "📈 매매타이밍" 버튼 추가

GitHub Pages (statepark62.github.io)
└── /stock/
    ├── index.html     — 웹 대시보드 (대시보드.html을 올린 것)
    └── icons/         — 파비콘 + 홈 화면 아이콘 + manifest.json
```

데이터 흐름: **야후/네이버 → 구글시트(저장·신호 계산) → 웹앱(JSON 변환, 한 달 이력 포함) → 웹 대시보드(카드 + 차트)**

## 2. 데이터 출처와 의미

| 대상 | 항목 | 출처 | 비고 |
|---|---|---|---|
| 미국 | 현재가, 50/200일 이평, RSI(14), 한 달 종가 | 야후 차트 API | 호출 한도 없음. 1년치 일봉으로 직접 계산 |
| 미국 | 배당수익률 | 야후 배당 이력 | **최근 12개월 실제 배당 합계 ÷ 현재가**. 분배금이 줄어드는 ETF는 예상치보다 높게 나올 수 있음 |
| 미국 | PER, 배당성향 | 네이버 해외주식 | 개별 주식만. **ETF는 `-`(해당 없음)**. 배당성향은 (최근 12개월 배당 ÷ EPS)로 추정 |
| 국내 | 현재가, PER, 배당수익률, 이평, RSI | 네이버 금융 | 배당성향은 (배당금 ÷ EPS × 100)으로 추정 |
| 국내 | 외국인·기관·개인 순매수 | 네이버 투자자별 매매동향 | 최근 5거래일 합계(주 단위) |

- **차트의 값은 일별 종가**입니다. 카드의 현재가는 갱신 시점의 가격이라 장중에는 차트 마지막 점과 다를 수 있습니다.
- 미국 장이 열려 있는 동안 갱신하면 장중 값은 이력에서 제외하고 직전 마감 종가까지만 사용합니다.
- 50일·200일 이평과 RSI는 모두 종가 기준으로 계산합니다.

### 수급 비율(국내 종목)
- **거래량 대비 순매수**: 최근 5거래일 순매수 합 ÷ 같은 기간 거래량 합 × 100. 외국인·기관·개인 각각 계산합니다.
- 기관·개인의 *지분율*은 공개 데이터가 없어 외국인 지분율만 표시합니다.
- 세 값을 더해도 0이 되지는 않습니다(연기금·기타 주체가 따로 있기 때문).

## 3. 신호 설명

| 신호 | 조건 | 의미 |
|---|---|---|
| 저평가 | PER ≤ 15 | 이익 대비 주가가 싸게 거래되는 중 |
| 배당위험 | 배당성향 > 100% | 버는 돈보다 배당을 더 많이 지급 중 — 삭감 가능성 |
| 과매도 | RSI ≤ 30 | 단기 과매도, 기술적 반등 가능성 |
| 과매수 | RSI ≥ 70 | 단기 과매수, 조정 가능성 |
| 200일선하회 | 현재가 < 200일 이동평균 | 장기 추세선 아래 — 원인 확인 필요 |
| 수급양호 | (국내) 외국인·기관 5일 순매수 모두 > 0 | 대형 투자자가 함께 사는 중 |
| 수급악화 | (국내) 외국인·기관 5일 순매수 모두 < 0 | 대형 투자자가 함께 파는 중 |

기준값은 각 파일 상단 `CONFIG` / `KR_CONFIG` 객체에서 숫자만 바꾸면 조정됩니다.
수급 신호는 이메일 알림 조건에는 포함되지 않고 화면에만 표시됩니다.

ETF는 PER·배당성향이 없으므로 저평가·배당위험 신호는 나오지 않습니다.
국내 종목의 배당성향은 DART 전자공시에서 별도 확인을 권장합니다.

## 4. 종목 추가/삭제하는 법

코드를 건드릴 필요 없이, **시트에 직접 입력**하면 자동으로 인식됩니다.

- **미국**: `매매타이밍` 탭 A열 빈 줄에 티커(예: `JEPQ`, `O`)만 입력
- **국내**: `국내매매타이밍` 탭 A열에 6자리 종목코드 입력 (B열 종목명은 갱신 시 자동)
  (종목코드는 셀 서식이 텍스트로 지정되어 있어 앞자리 0이 보존됩니다.
  혹시 사라지면 `'000660`처럼 앞에 작은따옴표를 붙여 재입력)

입력 후 구글시트 메뉴 **📈 매매타이밍 > 미국 종목 갱신 / 국내 종목 갱신 / 전체 갱신**을 누르면 반영됩니다.
삭제는 해당 행을 지우면 됩니다. 웹앱 재배포는 필요 없습니다.

## 5. 설치 순서 (처음 설정할 때)

API 키는 필요 없습니다.

1. 구글시트에서 확장 프로그램 > Apps Script 열기
2. 아래 파일을 만들고 각각 코드를 붙여넣기 (Code.gs는 기본 파일 사용)
   `Code.gs`, `미국야후.gs`, `국내종목.gs`, `이력.gs`, `웹앱.gs`, `메뉴.gs`
3. 함수 실행 순서 (함수 선택 후 실행, 권한 승인 창이 뜨면 허용):
   - 미국: `setupSheet` → `updateUsData` → `createUsDailyTrigger`
   - 국내: `setupKrSheet` → `updateKrData` → `createKrDailyTrigger`
   - ⚠️ Code.gs의 `createDailyTrigger`는 실행하지 마세요 (옛 방식 함수를 매일 실행하게 됨)
4. **배포 > 새 배포 > 웹 앱**으로 배포 (실행 계정: 나, 액세스: 전체) → URL 복사
5. `대시보드.html`의 `WEBAPP_URL` 값을 4번에서 복사한 URL로 교체
6. `대시보드.html`을 `index.html`로, `icons/` 폴더와 함께 GitHub Pages(`/stock/`)에 업로드
7. 구글시트 새로고침(F5) → 상단 메뉴에 "📈 매매타이밍" 생김

### 코드를 수정했을 때
- **Apps Script 코드 수정**: 저장만으로는 웹 앱에 반영되지 않습니다.
  `배포 > 배포 관리 > 연필 아이콘 > 새 버전 > 배포`로 재배포하세요.
  (`새 배포`를 만들면 URL이 바뀌어 대시보드가 끊어집니다)
- **메뉴.gs 수정**: 저장 후 구글시트 탭을 새로고침(F5)해야 메뉴가 갱신됩니다.
  새로고침 전에는 메뉴가 옛 함수를 계속 실행합니다.
- **index.html 수정**: GitHub에 덮어쓴 뒤 브라우저에서 강력 새로고침(Ctrl+Shift+R).

## 6. 자동 실행 주기

매일 오전 8시(KST), 미국·국내 종목이 각각 자동 갱신되고 신호가 있으면 이메일로 알림이 옵니다.
수동 갱신은 구글시트 메뉴 **📈 매매타이밍 > 전체 갱신**을 누르면 됩니다.
웹 대시보드의 한 달 차트 데이터는 페이지를 열 때 가져오며, 서버에 20분간 캐시됩니다.

## 7. 알려진 제약 사항 / 트러블슈팅

| 증상 | 원인 | 해결 |
|---|---|---|
| 메뉴로 미국 갱신했더니 값이 모두 `-`로 지워짐, 종목당 40초씩 걸림 | 메뉴가 옛 함수(`updateAllData`, Alpha Vantage)를 실행 | `메뉴.gs`가 `updateUsData`를 가리키는지 확인 → 시트 새로고침(F5) → `updateUsData`를 직접 실행해 복구 |
| 매일 아침 값이 지워짐 | 자동 트리거가 옛 함수를 가리킴 | `createUsDailyTrigger` 실행 (트리거 목록에 `updateUsData`만 있어야 함) |
| 미국 종목 PER이 `-` | ETF이거나, 네이버 해외 응답에서 PER 항목을 못 찾음 | ETF는 정상. 개별 주식이면 실행 로그의 `PER/EPS 항목을 못 찾음` 줄을 확인 |
| 시트에 `오류: 야후 …` | 야후(비공식 주소) 접속 제한 또는 잘못된 티커 | 티커 확인 후 잠시 뒤 재시도 |
| "Unexpected end of JSON input" (국내) | 네이버가 Referer 헤더 없는 요청을 차단 | 코드에 Referer 헤더 추가 완료 |
| 일별시세 호출 시 400 오류 | `pageSize`를 크게 요청하면 거부됨 | 60개 이하로 나눠 요청하도록 처리 완료 |
| 티커 앞자리 0이 사라짐(`005930`→`5930`) | 구글시트가 숫자로 자동 인식 | A열 텍스트 서식(`@`) 지정됨. 그래도 사라지면 `'005930`으로 입력 |
| 대시보드에 "설정 필요" | index.html의 `WEBAPP_URL`이 기본값 | 배포 URL로 교체 후 업로드 |
| 한 달 차트에 "종가 이력이 아직 없습니다" | 웹앱 재배포 누락, 또는 외부 API 일시 오류 | 새 버전으로 재배포 → 잠시 뒤 새로고침 |
| `CONFIG가 이미 선언됨` 구문 오류 | 같은 파일에 코드를 중복으로 붙여넣음 | 파일 전체를 지우고 한 번만 붙여넣기 |
| 야후/네이버 접속 자체가 막힘 | 둘 다 비공식 API라 구조가 바뀌거나 막힐 수 있음 | 진단 함수(`testKrApi`, `testUsApi`류)로 응답 확인 |

### 정리해도 되는 파일
`미국진단.gs`, `미국대체진단.gs`, `수급테스트.gs`는 원인 확인용 진단 파일이라, 필요 없으면 Apps Script에서 삭제해도 됩니다.
Alpha Vantage를 더 이상 쓰지 않으므로 스크립트 속성의 `ALPHA_VANTAGE_KEY`도 지워도 됩니다.

### 과거에 있었던 변경
- 미국 데이터는 처음에 Alpha Vantage를 썼으나, `OVERVIEW`(PER·배당·이평)가 유료로 바뀌고 하루 25회 한도가 자주 소진되어 야후+네이버로 교체했습니다.

## 9. 사용 기술

- Google Sheets / Google Apps Script (자동화·저장)
- 야후 파이낸스 차트 API(미국 주가·배당 이력), 네이버 해외주식 API(미국 PER·EPS) — 모두 비공식
- 네이버페이 증권 비공식 JSON API (국내 주가·재무·투자자별 수급)
- HTML/CSS/JS 정적 페이지(직접 그린 SVG 차트) + GitHub Pages (대시보드)
