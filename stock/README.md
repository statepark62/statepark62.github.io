# 매매 타이밍 대시보드

보유·관심 종목(미국/국내)의 PER, 배당수익률, 배당성향, 이동평균, RSI를 매일 자동으로 수집하고,
조건에 맞으면 신호를 표시 + 이메일로 알려주는 개인용 투자 보조 도구입니다.
구글시트(데이터 저장·연산) + Apps Script(자동화) + 정적 웹페이지(한눈에 보기) 조합으로 만들었습니다.

> ⚠️ 이 도구는 참고용 신호를 보여줄 뿐입니다. 실제 매수/매도 판단은 실적·뉴스 등을
> 직접 확인한 뒤 내려야 하며, 투자 손실에 대한 책임을 지지 않습니다.

---

## 1. 전체 구조

```
구글 스프레드시트 (1개 파일)
├── 시트: 매매타이밍        (미국 종목)
├── 시트: 국내매매타이밍     (국내 종목)
│
└── Apps Script (같은 프로젝트 안 여러 .gs 파일)
    ├── Code.gs       — 미국 종목: Alpha Vantage API로 데이터 수집
    ├── 국내종목.gs    — 국내 종목: 네이버 금융 비공식 API로 데이터 수집
    ├── 웹앱.gs        — 시트 데이터를 JSON으로 내보내는 창구 (Web App 배포)
    └── 메뉴.gs        — 구글시트 메뉴에 "📈 매매타이밍" 버튼 추가

GitHub Pages (statepark62.github.io)
└── /stock/
    ├── index.html     — 웹 대시보드 (대시보드.html을 올린 것)
    └── icons/         — 파비콘 + 홈 화면 아이콘 + manifest.json
```

데이터 흐름: **API → 구글시트(저장/신호 계산) → 웹앱(JSON 변환) → 웹 대시보드(시각화)**

---

## 2. 신호 설명

| 신호 | 조건 | 의미 |
|---|---|---|
| 저평가 | PER ≤ 15 | 이익 대비 주가가 싸게 거래되는 중 |
| 배당위험 | 배당성향 > 100% | 버는 돈보다 배당을 더 많이 지급 중 — 삭감 가능성 |
| 과매도 | RSI ≤ 30 | 단기 과매도, 기술적 반등 가능성 |
| 과매수 | RSI ≥ 70 | 단기 과매수, 조정 가능성 |
| 200일선하회 | 현재가 < 200일 이동평균 | 장기 추세선 아래 — 원인 확인 필요 |

기준값은 각 파일 상단 `CONFIG` / `KR_CONFIG` 객체에서 숫자만 바꾸면 조정됩니다.

국내 종목의 **배당성향은 네이버가 직접 제공하지 않아 (배당금 ÷ EPS × 100)으로 추정 계산**한
값입니다. 정확한 수치는 DART 전자공시에서 별도 확인을 권장합니다.

## 3. 종목 추가/삭제하는 법

코드를 건드릴 필요 없이, **시트에 직접 입력**하면 자동으로 인식됩니다.

- **미국**: `매매타이밍` 탭 A열 빈 줄에 티커(예: `KO`)만 입력
- **국내**: `국내매매타이밍` 탭 A열에 6자리 종목코드, B열에 종목명 입력
  (종목코드는 셀 서식이 텍스트로 지정되어 있어 앞자리 0이 보존됩니다.
  혹시 사라지면 `'000660`처럼 앞에 작은따옴표를 붙여 재입력)

입력 후 구글시트 메뉴 **📈 매매타이밍 > 전체 갱신**을 누르면 바로 반영됩니다.
삭제는 해당 행을 지우면 됩니다.

## 4. 설치 순서 (처음 설정할 때)

1. **Alpha Vantage API 키 발급**: https://www.alphavantage.co/support/#api-key (무료, 이메일만 입력)
2. 구글시트에서 확장 프로그램 > Apps Script 열기
3. 아래 순서로 파일을 만들고 각각 코드를 붙여넣기
   - `Code.gs` (미국 종목 — 기본 Code.gs 파일 사용)
   - `국내종목.gs`
   - `웹앱.gs`
   - `메뉴.gs`
4. 프로젝트 설정(톱니바퀴) > 스크립트 속성에서
   `ALPHA_VANTAGE_KEY` = 발급받은 키 추가
5. 함수 실행 순서:
   - `setupSheet` → `updateAllData` → `createCharts` → `createDailyTrigger`
   - `setupKrSheet` → `updateKrData` → `createKrCharts` → `createKrDailyTrigger`
6. `웹앱.gs`는 **배포 > 새 배포 > 웹 앱**으로 배포 (실행 계정: 나, 액세스: 전체) → URL 복사
7. `대시보드.html`의 `WEBAPP_URL` 값을 6번에서 복사한 URL로 교체
8. `대시보드.html` + `icons/` 폴더를 GitHub Pages에 업로드
9. 구글시트 새로고침 → 상단 메뉴에 "📈 매매타이밍" 생김 (이후로는 Apps Script 편집기 없이 메뉴로 실행 가능)

---

## 5. 자동 실행 주기

매일 오전 8시(KST), 미국·국내 종목 각각 자동으로 갱신되고 신호가 있으면 이메일로 알림이 옵니다.
수동으로 갱신하려면 구글시트 메뉴 **📈 매매타이밍 > 전체 갱신**을 누르면 됩니다.

## 6. 알려진 제약 사항 / 트러블슈팅

| 증상 | 원인 | 해결 |
|---|---|---|
| 모든 값이 `#NUM!` | API가 빈 값을 줬는데 숫자로 변환 시도해서 발생 | 이미 코드에서 `-`로 표시되도록 수정 완료 |
| 모든 값이 `-`이고 응답은 정상(200) | Alpha Vantage 하루 호출 한도(25회) 초과 | 미국 동부시간 자정(한국시간 오후 1~2시경) 이후 재시도 |
| "Unexpected end of JSON input" (국내) | 네이버가 Referer 헤더 없는 요청을 차단 | 이미 코드에서 Referer 헤더 추가해 해결 완료 |
| 일별시세 호출 시 400 오류 | `pageSize`를 한 번에 크게(220 등) 요청하면 거부됨 | 60일씩 나눠 페이지네이션하도록 수정 완료 |
| 티커 앞자리 0이 사라짐(`005930`→`5930`) | 구글시트가 숫자로 자동 인식 | A열을 텍스트 서식(`@`)으로 미리 지정해둠. 그래도 사라지면 `'005930`처럼 입력 |
| `CONFIG가 이미 선언됨` 구문 오류 | 같은 파일에 코드를 중복으로 붙여넣음 | 파일 전체를 지우고 한 번만 붙여넣기 |
| 네이버/Alpha Vantage API 자체가 막힘 | 두 곳 다 비공식/무료 API라 구조가 바뀌거나 막힐 수 있음 | 발생 시 진단 함수(`testKrApi`, `testUsApi`)로 원인 확인 후 재문의 |
