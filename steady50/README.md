# 맨몸 챌린지

40·50대부터 집에서 시작하는 맨몸운동 안내 페이지입니다. 초급·중급·고급 단계를 고르면 월~금 운동 안내와 동작 그림이 바로 나타납니다. 서버 없이 동작하는 정적 웹페이지이며 GitHub Pages로 배포합니다.

## 화면 구성

| 구분 | 내용 |
|---|---|
| 초급 · 기본 15동작 | 처음 시작할 때. 팔 돌리기, 스쿼트, 플랭크 등 |
| 중급 · 추가 5동작 | 팔벌려뛰기, 마운틴 클라이머, 바이시클 크런치, 덩키 킥, 하이 니 |
| 고급 · 15동작 | 푸시업 변형, 한 다리 운동, 최상급(물구나무, 턱걸이 등) |

- 단계 카드를 누르면 그 단계가 **오늘의 운동**으로 저장되고(★ 표시), 월~금 안내와 운동 그림이 아래에 나타납니다.
- 운동은 월·수·금 3일, 화·목은 휴식(가볍게 걷기)입니다. 오늘 요일에는 "(오늘)"이 표시됩니다.
- 운동 그림을 누르면 크게 볼 수 있습니다.
- 마지막으로 고른 단계는 이 기기의 브라우저에 저장되어, 다시 열면 그 단계의 안내가 바로 보입니다.

## 파일 목록

| 파일·폴더 | 설명 |
|---|---|
| `index.html` | 초기화면(단계 선택, 월~금 안내, 운동 그림) |
| `basic19.html` | 초급 동작 인쇄물 (내용은 15동작, 9쪽) |
| `extra5.html` | 중급 추가 동작 인쇄물 (5동작, 4쪽) |
| `hard15.html` | 고급 동작 인쇄물 (15동작, 9쪽) |
| `app.html` | 타이머·동작 시범·배경음악이 있는 기존 운동 앱 (초기화면에서 연결되어 있지 않음) |
| `img/` | 초기화면에 표시되는 운동 그림 (`basic19_*`, `extra5_*`, `hard15_*`) |
| `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png`, `favicon.ico`, `icon.svg` | 홈 화면 추가용 아이콘과 설정 |

인쇄물 3개 페이지에는 왼쪽 위에 "← 처음으로 돌아가기" 버튼이 있고, 인쇄할 때는 나타나지 않습니다.

## GitHub Pages로 올리는 방법

1. 이 폴더의 파일과 `img` 폴더를 저장소 맨 위(루트)에 모두 올립니다. 기존 파일은 덮어씁니다.
2. 저장소의 Settings → Pages에서 Source를 `main` 브랜치, 폴더는 `/ (root)`로 지정합니다.
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 주소에서 초기화면이 열립니다.

주의할 점
- `img` 폴더가 빠지면 운동 그림이 보이지 않습니다.
- 파일 이름은 영문을 유지하세요. 한글 파일명은 링크가 끊기는 경우가 있었습니다.
- `index.html`을 파일로 직접 열어도 되지만, 휴대폰에서는 GitHub Pages 주소로 여는 것이 가장 안정적입니다.
- 홈 화면에 앱을 추가해 두었다면, 새 버전이 보이지 않을 때 지웠다가 다시 추가합니다.

## 인쇄하는 방법

`basic19.html`, `extra5.html`, `hard15.html`을 열고 브라우저 인쇄(Ctrl+P)에서 용지 A4, 여백 기본, 배경 그래픽 켬으로 설정합니다. 한 장에 두 동작씩 인쇄됩니다.

## 내용을 고치려면

- 단계별 월~금 운동 목록과 횟수는 `index.html` 안의 `DATA`에 있고, 운동 그림 목록은 `FIG`에 있습니다.
- 앱(`app.html`)의 단계별 루틴은 파일 안의 `LV`에 있습니다. 초급·중급·고급 루틴은 초기화면 안내와 같은 내용입니다.
- 그림의 해상도는 Gemini 캡처 화면을 기준으로 해서 낮습니다. 원본 이미지가 있으면 `img` 폴더의 파일을 같은 이름으로 바꾸면 됩니다.

## 안전 안내

운동 중 통증, 어지러움, 가슴 답답함이 있으면 즉시 중단하세요. 혈압·심장·관절에 문제가 있으면 의사와 상담한 뒤 시작하고, 고급 동작은 쉬운 단계가 충분히 편해진 뒤에 합니다. 이 자료는 개인용 운동 안내이며 의학적 조언이 아닙니다.
