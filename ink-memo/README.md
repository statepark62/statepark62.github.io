# 잉크메모 (Ink Memo)

암호로 잠그는 개인 메모 웹앱. 서버 없이 GitHub Pages로 배포되며, 메모는 사용자 본인의 Google Sheets에 암호화된 상태로 저장됩니다.

## 무엇을 하는 앱인가

카카오톡 "나에게 보내기"로 메모를 남기다 보면 나중에 찾기가 어렵습니다. 잉크메모는 그 습관을 그대로 살리면서, 검색과 태그 분류를 더한 개인 메모장입니다.

- 한 줄 입력으로 빠르게 기록
- `#태그`를 본문에 쓰면 자동 인식 — 태그별로 모아보기
- 실시간 검색 (내용·태그)
- 고정(핀), 수정, 삭제
- 날짜별 자동 그룹핑
- PC·모바일 어디서든 같은 메모 (Google 계정 기준 동기화)

## 보안 구조

두 겹의 보호 장치가 있습니다.

| 계층 | 역할 |
|---|---|
| **Google 로그인** | 누구의 데이터인지 구분. 각 사용자는 본인 Drive의 스프레드시트에만 접근 |
| **암호(passphrase)** | 그 시트 안의 내용을 다시 잠금. 암호를 모르면 복호화 불가 |

- 암호는 **어디에도 저장되지 않습니다.** PBKDF2(250,000회 반복)로 키를 파생해 AES-GCM으로 암호화하며, 암호 자체는 브라우저 메모리에만 잠시 존재합니다.
- 스프레드시트에는 **암호화된 문자열만** 저장됩니다. 시트를 직접 열어봐도 내용을 읽을 수 없습니다.
- 앱 개발자를 포함해 제3자는 사용자의 시트에 접근할 수 없습니다. 데이터는 각 사용자의 Google 계정 권한 안에만 존재합니다.
- 암호를 분실하면 저장된 메모를 복구할 방법이 없습니다. 이는 설계상 의도된 것입니다.

## 기술 스택

- **호스팅**: GitHub Pages (정적 파일, 별도 서버 없음)
- **인증**: Google Identity Services (OAuth 2.0)
- **저장소**: Google Sheets API v4 + Google Drive API v3 (`appDataFolder`)
- **암호화**: Web Crypto API (PBKDF2 + AES-GCM 256bit)
- **프론트엔드**: 단일 HTML 파일 (외부 프레임워크 없음)

`appDataFolder`는 사용자 Drive에 보이지 않는 앱 전용 숨김 공간입니다. 여기에 "이 사용자의 메모 시트가 어느 것인지"를 가리키는 포인터 파일만 저장하고, 실제 메모는 일반 스프레드시트에 보관합니다.

## 설치 및 배포

### 1. Google Cloud Console 설정

1. [Google Cloud Console](https://console.cloud.google.com)에서 새 프로젝트 생성
2. **API 및 서비스 → 라이브러리**에서 다음 두 API 활성화
   - Google Sheets API
   - Google Drive API
3. **OAuth 동의 화면** 구성
   - User Type: 외부(External)
   - 게시 상태: 테스트(Testing)
   - 범위(Scopes) 추가:
     - `https://www.googleapis.com/auth/spreadsheets`
     - `https://www.googleapis.com/auth/drive.appdata`
   - **테스트 사용자**에 사용할 사람들의 Google 계정 이메일 등록 (최대 100명)
4. **사용자 인증 정보 → OAuth 클라이언트 ID 만들기**
   - 애플리케이션 유형: **웹 애플리케이션**
   - 승인된 JavaScript 원본: `https://<사용자명>.github.io`
   - 생성된 클라이언트 ID 복사

### 2. 앱 설정

`index.html`에서 다음 값을 실제 클라이언트 ID로 교체합니다.

```javascript
const CLIENT_ID = "여기에_OAuth_클라이언트_ID를_입력하세요.apps.googleusercontent.com";
```

### 3. 배포

`index.html`과 `apple-touch-icon.png`를 리포지토리에 올린 뒤, **Settings → Pages**에서 브랜치와 폴더를 지정하면 배포됩니다.

> OAuth 설정 변경은 반영에 5분에서 수 시간까지 걸릴 수 있습니다.

## 사용법

### 태그로 분류하기

메모 본문 어디에든 `#태그` 형태로 쓰면 자동 인식됩니다.

```
우유, 계란, 두부 사기 #쇼핑
다음 주 발표자료 검토 #강의 #급함
```

저장하면 상단에 태그 칩이 생기고, 클릭하면 해당 태그의 메모만 필터링됩니다. 한 메모에 여러 태그를 붙일 수 있습니다.

태그는 일관되게 쓰는 것이 좋습니다. `#쇼핑`과 `#장보기`는 서로 다른 태그로 인식됩니다.

### 백업과 복원

- **내보내기**: 전체 메모를 JSON 파일로 저장. 이 파일은 **암호화되지 않은 평문**이므로 보관에 주의하세요.
- **불러오기**: JSON 백업을 읽어 기존 메모와 병합합니다. 같은 메모(동일 ID)는 자동으로 건너뛰므로 중복이 쌓이지 않으며, 기존 메모는 삭제되지 않습니다.

### 잠그기

"잠그기"를 누르면 암호 입력 화면으로 돌아갑니다. Google 로그인은 유지되므로 암호만 다시 입력하면 됩니다. 탭을 완전히 닫으면 로그인부터 다시 해야 합니다.

## 모바일에서 사용하기

iOS Safari에서 접속 후 **공유 → 홈 화면에 추가**하면 앱처럼 전체화면으로 실행됩니다. 안전 영역(노치·홈 인디케이터) 여백과 입력 시 자동 확대 방지가 적용되어 있습니다.

> 이미 추가한 아이콘은 앱을 업데이트해도 자동 반영되지 않습니다. 아이콘을 삭제하고 다시 추가하세요.

## 사용자 추가하기

Google Cloud Console → **OAuth 동의 화면 → 테스트 사용자**에 해당 사용자의 Google 계정 이메일을 추가하면 됩니다. 앱 코드는 수정할 필요가 없습니다.

각 사용자는 본인 Drive에 자신만의 스프레드시트가 자동 생성되며, 서로의 메모를 볼 수 없습니다.

## 알려진 제약

- 테스트 모드에서는 등록된 테스트 사용자(최대 100명)만 로그인할 수 있습니다. 그 이상 공개하려면 Google의 앱 검토 절차가 필요합니다.
- 로그인 세션은 탭이 닫히면 만료됩니다. 방문할 때마다 짧은 로그인 절차를 거칩니다.
- 암호 분실 시 복구 수단이 없습니다. 정기적인 내보내기를 권장합니다.
