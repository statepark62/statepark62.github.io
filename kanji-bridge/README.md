# 한자 징검다리 (kanji-bridge)

한국어에 이미 있는 한자어(학교·학생 등)를 **디딤돌**로 삼아, 일본어 한자의 음독을 익히도록 돕는 학습 웹앱입니다.
한자를 거의 모르는 한국 젊은 학습자를 위해 만들었습니다.

- 앱 주소: https://statepark62.github.io/kanji-bridge/
- 대상: JLPT N5 · N4 · N3 한자 612자
- 설치 없이 브라우저에서 열고, 휴대폰 홈 화면에 추가하면 앱처럼 쓸 수 있습니다(PWA, 오프라인 지원).

## 주요 기능

| 기능 | 설명 |
|---|---|
| 한국음 → 일본 음독 연결 | 한국 한자음의 받침(ㄱ→く/き, ㅂ→う, ㄹ→つ/ち, ㄴ·ㅁ→ん, ㅇ→う/い)으로 일본 음독의 끝소리를 짐작하게 합니다. |
| 한자 카드 | 훈음, 자형 설명, 연상, 음독 연결 설명, 예외 읽기, 훈독 팁, 예시 단어 |
| 헷갈리는 단어 | 한자·소리는 같지만 한국어와 뜻이 다른 단어(예: 勉強 ≠ 면강)를 따로 모아 보여 줍니다. |
| 퀴즈와 복습 | 간격 반복(1일 → 3일 → 7일 → 14일 → 30일). 맞히면 단계가 오르고, 틀리면 두 단계 내려갑니다. |
| 쓰기 연습 | 획순 보기, 따라 쓰기, 기억해서 쓰기(KanjiVG 획순 데이터) |
| 구글 계정 동기화 | 로그인하면 학습 기록이 본인 구글 드라이브의 앱 전용 공간에 저장되어 기기 간에 이어집니다. |
| 접속 기록·피드백 | 접속 기록과 설정의 피드백, 한자 카드의 오류 신고가 별도 구글 시트에 쌓입니다. |

## 파일 구성

```
index.html        화면 뼈대
style.css         스타일
app.js            앱 본체(화면, 퀴즈, 복습, 계정 동기화, 로그·피드백)
sheet.js          구글 시트 CSV를 읽어 앱 데이터로 조립
cloud.js          구글 로그인과 드라이브 동기화, 기록 병합 규칙
data.js           앱에 내장된 한자 데이터(시트를 못 읽을 때의 대비용)
strokes.js        획순 데이터(KanjiVG)
config.js         시트 주소와 구글 클라이언트 ID  ← 직접 입력, 아래 참고
logconfig.js      접속 기록·피드백 수신 주소와 키  ← 직접 입력, 아래 참고
sw.js             서비스 워커(오프라인 캐시)
manifest.json     홈 화면 추가 설정
privacy.html      개인정보 처리 안내
terms.html        이용 안내
icons             아이콘
```

## 데이터가 흐르는 방식

```
구글 시트(kanji_sheet) ──웹에 게시(CSV)──▶ 앱이 열릴 때 읽음 ──▶ 화면
        │                                         │
        └ 읽기에 실패하면 ─────────▶ 내장 data.js를 사용
```

- **시트가 원본**입니다. 시트의 `한자` 탭과 `단어` 탭을 고치면 앱이 다음에 열릴 때 반영됩니다.
- 앱은 시트를 읽을 수 없으면 내장 `data.js`로 동작하고, 설정 화면에 데이터 출처가 표시됩니다.
- 학습 기록은 브라우저 `localStorage`(`kj_state_v1`)에 저장되고, 로그인하면 드라이브에도 올라갑니다.

### 시트의 표시 규칙

- **연상**: `AI검수요청`이 "예"인 한자는 `검수` 칸이 `OK` 또는 `수정함`일 때만 보입니다. `제외`이면 숨깁니다.
- **단어**: `숨김`이 `Y`이거나 `검수`가 `제외`이면 숨깁니다.
- **헷갈리는 단어**: `relation`이 `false_friend`이거나 `주의단어`가 `Y`인 단어.
- **예시 단어**: `relation`이 `same` 또는 `similar`이고 `keep`이 `1`이며 `신뢰도`가 `low`가 아닌 단어.
- 예시 단어가 하나도 없는 한자는 "징검다리 약함"으로 표시됩니다.
- `급` 열: 5(N5), 4(N4), 3(N3). 첫 줄의 열 이름은 바꾸지 마세요(열 순서는 바꿔도 됩니다).

> 이 시트는 **웹에 게시(전체 문서)** 상태입니다. 비밀이거나 개인적인 탭을 이 시트에 추가하지 마세요. 접속 기록과 피드백은 반드시 별도 시트에 둡니다.

## 처음 설정하기

### 1. config.js

```js
window.KJ_CONFIG = {
  kanjiCsv: '시트 한자 탭의 게시 CSV 주소',
  wordCsv:  '시트 단어 탭의 게시 CSV 주소',
  googleClientId: '구글 클라우드의 OAuth 클라이언트 ID'
};
```

- CSV 주소는 `https://docs.google.com/spreadsheets/d/e/…/pub?gid=…&single=true&output=csv` 형태입니다. 편집 주소(`…/edit?gid=`)나 `pubhtml` 주소가 아닙니다.
- 구글 클라이언트 ID는 비밀 값이 아닙니다(클라이언트 보안 비밀은 쓰지 않습니다). 허용된 도메인에서만 동작합니다.
- 이 파일은 네트워크 우선으로 읽도록 해 두었으니, 고치면 바로 반영됩니다.

### 2. logconfig.js

```js
window.KJ_LOG = {
  url: 'Apps Script 웹 앱 주소(/exec로 끝남)',
  key: 'Code.gs의 KEY와 같은 문자열'
};
```

- 비워 두면 접속 기록과 피드백 기능이 꺼집니다.
- `key`는 공개 저장소에 올라가므로, 약한 스팸 방지용 값이라고 생각하세요. 시트 자체는 이 키로 읽을 수 없습니다.

### 3. 구글 로그인(OAuth) 설정

- 구글 클라우드 프로젝트(`japan-kanji`)에서 OAuth 동의 화면과 클라이언트 ID를 만듭니다.
- 범위는 `https://www.googleapis.com/auth/drive.appdata` **하나만** 씁니다(앱 전용 공간만 접근).
- 승인된 자바스크립트 원본에 `https://statepark62.github.io`를 넣습니다.
- 동의 화면의 홈페이지·개인정보·약관 주소는 `privacy.html`, `terms.html`을 가리킵니다.

### 4. 접속 기록·피드백 수신(Apps Script)

1. **새 구글 시트**를 만듭니다(콘텐츠 시트와 별개, 게시하지 않음).
2. 확장 프로그램 → Apps Script에 `Code.gs`를 붙여 넣고, 맨 위 `KEY`를 임의의 긴 문자열로 바꿉니다.
3. `authorizeMail` 함수를 한 번 실행해 메일 발송 권한을 승인합니다(피드백 알림 메일용).
4. 배포 → 새 배포 → 유형 "웹 앱", 실행 계정 "나", 액세스 권한 "모든 사용자"로 배포합니다.
5. 나온 `/exec` 주소와 `KEY`를 `logconfig.js`에 넣습니다.
6. 코드를 고친 뒤에는 **배포 관리에서 새 버전으로 다시 배포**해야 반영됩니다(주소는 그대로).

기록되는 탭: `접속기록`, `사용자`, `피드백`. 피드백이 들어오면 배포한 계정으로 알림 메일이 갑니다(받는 주소는 `NOTIFY`로 바꿀 수 있고, `'off'`로 끌 수 있습니다).

## 업데이트(배포)하는 방법

1. 바뀐 파일을 GitHub 저장소(`kanji-bridge`)에 올려 덮어씁니다.
2. **`config.js`와 `logconfig.js`는 실제 값이 들어 있으니 함부로 덮어쓰지 마세요.**
3. 앱 파일(`app.js`, `data.js`, `strokes.js`, `style.css` 등)을 바꿨다면 `sw.js`의 `VERSION`(예: `kj-v20`)을 올려야 사용자에게 새 버전이 전달됩니다.
4. 올린 뒤 앱을 열고 한두 번 새로고침해 새 버전이 뜨는지 확인합니다.

## 한자 추가·수정하기

- **고치기**: 시트의 해당 셀을 고치면 됩니다(앱에서 "지금 갱신"으로 바로 확인).
- **새 급수 추가하기**: 기존 방식대로 한자 표 → 한국어 대응 단어 → AI 초안 → 시트 순으로 만든 뒤, 한자·단어 탭에 행을 **붙여 넣습니다**(시트에서 파일 → 가져오기 → "현재 시트에 데이터 추가", "텍스트를 숫자·날짜·수식으로 변환" 해제).
  - 급수가 바뀌는 업데이트는 **앱 파일을 먼저 올린 뒤** 시트에 행을 추가하세요. 그래야 예전 버전 앱이 새 급수를 잘못 섞어 보여 주지 않습니다.
  - 새 한자의 획순은 `strokes.js`에 넣고, 내장 데이터 `data.js`도 다시 만들어 올립니다.
- 오류 신고는 앱의 한자 카드에서 "오류 신고"로 들어와 시트의 `피드백` 탭에 `[한자 / 항목] 내용`으로 쌓입니다.

## 개인정보

- 학습 기록은 기본적으로 이 기기에만 저장됩니다.
- 구글 로그인을 하면 본인 드라이브의 **앱 전용 공간**에만 기록이 저장되며, 드라이브의 다른 파일은 볼 수 없습니다.
- 접속 기록에는 익명 기기 번호, 접속 시각, 공부한 한자 수, 앱 버전, 기기 정보가 남고, 로그인한 경우 이메일이 함께 남습니다.
- 자세한 내용과 삭제 요청 방법은 `privacy.html`에 있습니다.

## 개발 메모

- 외부 라이브러리 없이 순수 JavaScript로 작성했습니다.
- 서비스 워커는 앱 파일을 캐시 우선으로 읽고, `config.js`와 `logconfig.js`는 네트워크 우선으로 읽습니다.
- 계정 동기화는 한자별로 "가장 최근 기록이 이긴다"는 규칙으로 병합하고, "학습 기록 모두 지우기"는 이후에 다른 기기의 오래된 기록이 되살아나지 않도록 표시를 남깁니다.
- 로그인 상태는 약 1시간마다 만료되며, 앱을 다시 열 때 조용히 재연결을 시도하고 안 되면 설정에서 다시 로그인하게 합니다.
