ことば帖 음성(발음) 설정 가이드

더 자연스러운 일본어 발음으로 공부하기 — 기기별 5분 설정

ことば帖의 발음은 여러분 기기에 설치된 일본어 음성이 냅니다. 그래서 기기마다 목소리가 다르고, 일본어 음성이 없는 기기에서는 소리가 안 나거나 어색하게 들립니다. 아래에서 본인 기기 항목 하나만 따라 하면 훨씬 또렷한 발음으로 공부할 수 있습니다. (읽는 내용 자체는 앱이 후리가나로 지정하므로 어떤 기기든 동일합니다 — 달라지는 것은 목소리의 품질입니다.)

📱 iPhone · iPad

기본 일본어 음성: Kyoko(女) — 고품질판을 내려받으면 음질이 크게 좋아집니다

  1. 설정 → 손쉬운 사용 → 읽기 및 말하기
    (iOS 버전에 따라 "콘텐츠 말하기"로 표시되기도 합니다. 안 보이면 설정 맨 위 검색창에 "말하기" 입력)
  2. 음성 → 언어 목록에서 일본어 선택
  3. Kyoko 항목에서 구름(⬇) 아이콘을 눌러 고품질 음성 다운로드 (Wi-Fi 권장, 수십 MB)
  4. 여러 음성이 보이면 미리듣기(▶)로 들어보고 마음에 드는 것을 선택

소리가 아예 안 나면 발음 이전에 측면 무음(진동) 스위치부터 확인하세요 — iPhone에서 가장 흔한 원인입니다.

🤖 Android (갤럭시 포함)

권장 엔진: Google 음성 서비스(Speech Services by Google) — 대부분 기기에 기본 탑재

  1. 설정에서 "TTS" 또는 "텍스트 음성 변환" 검색 → 해당 메뉴 진입
    (경로 예: 설정 → 일반(시스템) → 언어 및 키보드 → 텍스트 음성 변환)
  2. 기본 엔진이 갤럭시 자체 TTS로 되어 있으면 Google 음성 서비스로 변경 (일본어 품질이 더 좋습니다)
  3. 엔진 옆 ⚙ 설정 → 음성 데이터 설치 → 일본어(日本語) 다운로드
  4. 같은 화면의 "예시 듣기"로 일본어가 정상 재생되는지 확인

Google 음성 서비스가 목록에 없으면 Play 스토어에서 "Google 음성 서비스"를 설치하세요.

💻 PC — Windows

Chrome: 인터넷 연결 시 구글 일본어 음성 자동 사용 · Edge: Nanami 등 자연스러운 음성 내장

  1. Chrome 사용자는 대개 추가 설정 없이 됩니다 (온라인 상태여야 함)
  2. 소리가 어색하면 Windows에 일본어 음성 추가: 설정 → 시간 및 언어 → 언어 및 지역 → 언어 추가 → 日本語 (음성 합성 체크) → 설치
  3. Edge 브라우저로 열면 별도 설정 없이 자연스러운 음성이 나오는 경우가 많으니, 발음이 중요하면 Edge도 시도해 보세요

🍎 PC — Mac

  1. 시스템 설정 → 손쉬운 사용 → 말하기 콘텐츠 → 시스템 음성 → 관리
  2. 일본어 항목에서 Kyoko(또는 O-Ren 등) 다운로드

✅ 설정 후 확인

ことば帖을 열고 아무 카드에서 🔊 버튼을 눌러보세요. 단어 → 예문 순으로 또렷하게 읽으면 성공입니다.

설정을 바꾼 뒤에는 앱을 완전히 종료했다가 다시 실행해야 새 음성이 적용되는 경우가 있습니다.

🔧 문제 해결

소리가 전혀 안 나요

① iPhone 무음 스위치 / 미디어 볼륨 확인 ② 앱 하단 "음성 읽기" 체크 확인 ③ 위 안내대로 일본어 음성 설치 ④ 앱 완전 종료 후 재실행

영어식으로 어색하게 읽어요

기기에 일본어 음성이 없어 다른 언어 음성이 대신 읽는 상태입니다. 본인 기기 항목의 안내대로 일본어 음성을 설치하면 해결됩니다.

목소리가 너무 기계음 같아요

저품질 기본 음성이 잡혀 있는 경우입니다. iPhone은 Kyoko 고품질판 다운로드, Android는 엔진을 Google 음성 서비스로 변경해 보세요.

예문이 끝까지 안 읽히고 중간에 끊겨요

고장이 아니라 카드 간격 설정 때문입니다. 자동재생은 정해진 간격(기본 7초)마다 다음 카드로 넘어가는데, 예문이 길면 낭독이 끝나기 전에 시간이 다 되어 소리가 끊깁니다. 자동학습 화면 하단의 "카드 간격" 슬라이더를 10~15초로 늘리면 긴 예문도 끝까지 들을 수 있습니다. 특정 카드만 천천히 듣고 싶을 때는 자동재생을 잠시 멈추고(⏸) 🔊 버튼을 누르면 단어와 예문을 끊김 없이 전부 읽어줍니다.

가족 폰과 목소리가 달라요

정상입니다. 목소리는 각 기기의 음성엔진이 내는 것이라 기기마다 다릅니다. 읽는 내용(발음)은 모든 기기에서 동일합니다.
