1이런 앱입니다

매일 자라는 단어장아사히신문 명칼럼 천성인어(天声人語)와 NHK 뉴스에서 뽑은 단어가 매일 아침 자동 추가됩니다.
N5~N1 기본 단어 내장JLPT 전 레벨 100단어 + 예문·번역·발음으로 바로 시작할 수 있습니다.
세 가지 학습 모드자동재생(흘려듣기) · 퀴즈 · 간격반복 복습(SRS)으로 과학적으로 외웁니다.
오프라인 지원한 번 접속한 뒤에는 지하철에서도 작동합니다. 학습 기록은 내 기기에만 저장됩니다.

2홈 화면에 추가하기 (1분)

위의 "앱 열기" 버튼으로 접속한 뒤:

iPhone — Safari에서
  1. 하단 가운데 공유 버튼(⬆)을 누릅니다.
  2. 아래로 내려 "홈 화면에 추가" → 추가.
Android — Chrome에서
  1. 화면에 "홈 화면에 ことば帖 추가" 안내가 뜨면 그대로 누르면 끝. 안 뜨면 우측 상단 ⋮ 메뉴 → "홈 화면에 추가".

카카오톡·네이버 앱 안에서 링크를 열었다면, 구석 메뉴에서 "다른 브라우저로 열기"(iPhone은 "Safari로 열기")를 먼저 눌러 주세요.

홈 화면에 붉은 낙관이 찍힌 「言」 아이콘이 생기면 완료 — 이제 앱처럼 눌러서 쓰면 됩니다.

3꼭 알아둘 한 가지 — 학습 기록 백업

학습 기록(복습 단계, 정답/오답)은 서버가 아니라 지금 이 기기 안에만 저장됩니다. 그래서 기기를 바꾸거나 브라우저 데이터를 지우면 기록이 사라질 수 있습니다.

  1. 단어장 탭 맨 아래의 "진도 내보내기"를 누르면 백업 파일이 저장됩니다.
  2. 그 파일을 카카오톡 '나에게 보내기'나 클라우드에 올려 두세요.
  3. 새 기기에서는 "진도 가져오기"로 파일을 선택하면 기록이 그대로 복원됩니다.

기록이 쌓이면 앱이 알아서 "백업하세요" 알림을 띄워 줍니다. 그때 한 번씩 눌러 주시면 충분합니다.

4추천 사용법

  1. 매일 복습 탭의 '오늘 복습'을 0으로 만들기 (5~10분)
  2. 자동학습으로 새 단어 흘려듣기 — 카드 간격·레벨(N5~N1)은 취향대로
  3. 퀴즈로 마무리 — 결과가 복습 일정에 자동 반영됩니다

발음이 어색하면 기기에 일본어 음성을 설치해 보세요. iPhone: 설정 → 손쉬운 사용 → 콘텐츠 말하기 → 음성 → 일본어 / Android: 설정에서 TTS 검색 → Google TTS → 일본어 음성 데이터.

5문제가 생기면

소리가 안 나요

iPhone 측면 무음 스위치를 확인하세요. 화면 하단 "음성 읽기" 체크와, 위 4번의 일본어 음성 설치도 확인.

새 단어가 안 보여요

단어는 매일 아침 추가됩니다. 앱을 완전히 닫았다가 다시 열거나, 화면을 당겨 새로고침해 보세요.

화면이 이상하거나 옛날 그대로예요

홈 화면 아이콘을 지우고 링크로 재접속해 다시 추가하면 해결됩니다. 단, 지우기 전에 3번의 백업을 먼저!

기기를 바꿨더니 기록이 없어요

기록은 기기별 저장이라 정상입니다. 이전 기기에서 만든 백업 파일을 단어장 탭 → 진도 가져오기로 불러오세요.
