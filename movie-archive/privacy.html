개인정보처리방침

서비스: 영화기록(영화 · 드라마 감상 아카이브) · 시행일: 2026년 10월 6일

'영화기록'(이하 "앱")은 사용자가 본 영화와 드라마의 감상을 기록하는 개인용 웹앱입니다. 이 방침은 앱이 어떤 정보에 접근하고, 어떻게 사용하며, 어디에 저장하는지 설명합니다.

1. 앱이 접근하는 정보

  • Google 계정 기본 정보: 이름, 이메일 주소, 프로필 사진. 로그인한 계정을 화면에 표시하고 사용자별 시트를 구분하는 용도로만 사용합니다.
  • Google Drive 파일(drive.file 권한): 앱이 사용자의 Drive에 직접 만든 시트('영화·드라마 감상 기록')에만 접근합니다. 사용자의 다른 Drive 파일은 보거나 변경할 수 없습니다.

2. 감상 기록의 저장 위치

  • 사용자가 입력한 관람 일자, 평점, 한줄평, 감상평 등은 사용자 본인의 Google Drive에 있는 시트에만 저장됩니다.
  • 앱 운영자의 서버나 데이터베이스에는 감상 기록이 저장되지 않으며, 운영자는 이 기록을 열람하거나 수집하지 않습니다.
  • 로그인 편의를 위해 브라우저(로컬 저장소)에 계정 이름, 이메일, 시트 식별자를 보관합니다. 로그아웃하면 삭제됩니다.

3. 작품 검색(TMDB)

  • 작품을 검색하면 입력한 검색어와 선택한 작품 번호가 TMDB(The Movie Database) 조회를 위해 중계 서버(Google Apps Script)를 거쳐 TMDB로 전달됩니다.
  • 이 요청에는 사용자의 이름이나 이메일 같은 개인 식별 정보가 포함되지 않으며, 검색어를 사용자와 연결해 저장하지 않습니다.
  • This product uses the TMDB API but is not endorsed or certified by TMDB.

4. 정보의 제공과 이용

  • 앱은 사용자의 정보를 제3자에게 판매, 공유, 제공하지 않습니다. 광고에도 사용하지 않습니다.
  • Google API로 받은 정보의 사용은 제한적 사용(Limited Use) 요건을 포함하여 Google API 서비스 사용자 데이터 정책을 준수합니다.

5. 권한 철회와 삭제

  • 앱 상단의 로그아웃을 누르면 앱이 받은 접근 권한이 폐기되고 브라우저에 보관된 정보가 삭제됩니다.
  • 언제든 Google 계정의 서드 파티 앱 및 서비스에서 이 앱의 접근 권한을 삭제할 수 있습니다.
  • 감상 기록은 사용자의 Drive에 있으므로, 해당 시트를 직접 삭제하면 기록이 모두 지워집니다.
