# 가톨릭 기도문 PWA

구글 시트 "가톨릭 기도문 DB"의 기도문 79건을 검색해서 쓰는 앱입니다. 서버가 필요 없는 정적 웹앱입니다.

## 올리는 방법 (GitHub Pages)
1. GitHub에 새 저장소를 만듭니다. (아래 '저작권' 항목을 먼저 읽어 주세요. 허락 전에는 Private 권장)
2. 이 폴더 안의 파일을 모두 저장소 최상위에 올립니다. (build 폴더는 올려도, 빼도 됩니다)
3. 저장소 Settings → Pages → Branch를 main / (root)로 지정합니다.
4. 몇 분 뒤 나오는 주소를 스마트폰 브라우저로 열고 '홈 화면에 추가'(iPhone) 또는 '앱으로 설치'(Android·PC)를 합니다.
   한 번 열어 두면 인터넷이 없어도 동작합니다.

## 시트 내용을 고치면 앱에 반영하는 방법
방법 A (자동 반영, 권장): 시트 `기도문` 탭을 [파일 → 공유 → 웹에 게시 → 기도문 탭 → 쉼표로 구분된 값(.csv)]으로 게시하고,
나온 주소를 config.js의 SHEET_CSV_URL에 붙여 넣습니다. 이후 앱을 열 때마다 최신 내용을 가져옵니다.
(주의: 웹에 게시하면 그 주소를 아는 누구나 시트 내용을 볼 수 있습니다.)

방법 B (수동): 시트 내용을 build/rows.json으로 갱신한 뒤 `python3 build/build.py`를 실행하면 prayers.js가 다시 만들어집니다.

## 화면 표기 규칙
○ 선창, ● 응답, ◎ 다 같이, ✝ 십자 표시, 빨간 [ ] 안내문, 밑줄(__ __)은 고개 숙이는 부분 등을 시트와 같은 기호로 보여 줍니다.
시트에서 '앱 표시'를 '숨김'으로 바꾸면 그 기도문은 앱에 나오지 않습니다.
