일본어 조리 용어

요리를 할 때 자주 쓰는 일본어 표현을 알아두면 정말 편리해요!

1. 기본 조리법 (가열)
일본어읽는 법의미설명
焼くやく (아쿠)굽다,굽기프라이팬이나 그릴에서 굽는 것
炒めるいためる (이타메루)볶다기름을 두르고 재료를 빠르게 볶는 것
煮るにる (니루)조리다,쭉 끓이다국물이나 소스에 넣고 졸이거나 푹 끓이는 것
茹でるゆでる (유데루)삶다끓는 물에 넣고 삶는 것
蒸すむす (무스)찌다수증기를 이용해 익히는 것
揚げるあげる (아게루)튀기다기름에 넣어 바삭하게 익히는 것
2. 자르기 / 썰기
일본어읽는 법의미설명
切るきる (키루)자르다칼로 자르는 일반적인 동작
刻むきざむ (키자무)다지다,잘게 썰다잘게 다져 써는 것
薄切りうすぎり (우스기리)얇게 썰기얇고 납작하게 써는 것
千切りせんぎり (센기리)채 썰기가늘고 길게 채 써는 것
角切りかくぎり (카쿠기리)깍둑썰기정사각형 모양으로 자르는 것
みじん切りみじんぎり (미진기리)곱게 다지기매우 잘게 다지는 것 미린조
3. 간 맞추기 / 양념
일본어읽는 법의미
味付けするあじつけする (아지츠케스루)간을 하다
混ぜるまぜる (마제루)섞다
和えるあえる (아에루)버무리다,무치다
漬けるつける (츠케루)절이다,담그다,재우다
4. 상태 / 정도
일본어읽는 법의미
焼き色をつけるやきいろをつける (야키이로오츠케루)겉면을 노릇하게 굽다
火を通すひをとおす (히오토-스)속까지 완전히 익히다
煮詰めるにつめる (니츠메루)국물을 졸이다
冷ますさます (사마스)식히다
5. 기타 자주 쓰는 표현
일본어읽는 법의미
下ごしらえするしたごしらえする (시타고시라에스루)손질하다(전처리)
水気を切るみずけをきる (미즈케오키루)물기를 빼다
盛り付けるもりつける (모리츠케루)예쁘게 담다
取り出すとりだす (토리다스)냄비나 그릇에서 꺼내다
