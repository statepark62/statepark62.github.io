한눈에 보는 일본어 동사 활용

동사의 기본형을 알고 형태를 바꾸면 일본어 회화가 쉬워져요!

1. 동사의 3가지 종류

Ⅰ그룹 (5단 활용)

어미가 う·く·す·つ·ぬ·む·ぶ·る 동으로 끝나는 동사

예) 書く, 話す, 食べる(×,예외 아님 주의), 飲む

Ⅱ그룹 (1단 활용)

い·え + る 형태로 끝나는 동사

예) 起きる, 見る, 食べる, 入る

Ⅲ그룹 (불규칙 활용)

する·くる 두 동사만 있어요

예) する, くる
2. 기본 활용형 (자주 사용)
활용형Ⅰ그룹(書く)Ⅱ그룹(起きる)Ⅲ그룹(する)Ⅲ그룹(くる)
기본형書く起きるするくる
~ます형書きます起きますしますきます
~ない형書かない起きないしないこない
~て형書いて起きてしてきて
~た형書いた起きたしたきた
3. 자주 쓰는 활용 예문
~ます형: 私は毎日ご飯を食べます。 (저는 매일 밥을 먹습니다.)
~ない형: 今日は時間がありません。 (오늘은 시간이 없습니다.)
~て형: 手を洗って、学校に行きます。 (손을 씻고, 학교에 갑니다.)
~た형: 昨日映画を見ました。 (어제 영화를 봤습니다.)
4. 동사 활용 규칙 (간단 정리)

Ⅰ그룹 (5단 활용)

어미에 따라 아래처럼 바뀌어요

う단 → いました / く단 → きました / る단 → 帰りました 처럼 각 행의 い단으로

Ⅱ그룹 (1단 활용)

어미 「る」를 빼고 ~ます, ~ない, ~て, ~た를 만들어요

起きる → 起きます / 起きない / 起きて / 起きた

Ⅲ그룹 (불규칙 활용)

암기해요!

する → します・しない・して・した
くる → きます・こない・きて・きた
5. 추가로 알아두면 좋은 표현
~てください: 開けてください。 (열어 주세요.)
~たい: 日本に行きたいです。 (일본에 가고 싶어요.)
~ましょう: 一緒に行きましょう。 (함께 갑시다!)
~そうだ: 雨が降りそうです。 (비가 올 것 같아요.)
✔ 동사 활용을 많이 사용해 보면서 익혀요! · 처음에는 큰소리로 읽으면서 입에 익혀요! · 매일 5분씩 복습하면 기억이 오래가요!
활용 순서 기억하기: 기본형 → ~ます형 → ~ない형 → ~て형 → ~た형 (이 순서대로 익히면 기억하기 쉬워요!)
