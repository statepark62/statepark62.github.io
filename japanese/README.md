## 자료의 특징

- 한국어 해설 중심: 문법 용어를 한국어 학습자 관점에서 풀어 설명
- 로마자·한글 발음 병기: 히라가나·가타카나를 몰라도 소리 내어 읽을 수 있도록 구성
- 인쇄·공유 친화적: 화면 열람과 이미지 저장 모두를 고려한 레이아웃
- 지속 확장: 새 주제가 계속 추가되며, 목록은 위 열람 주소에서 확인
