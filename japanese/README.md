# 일본어 학습 콘텐츠 (Japanese Learning Contents)

일본어 문법·표현·독해를 주제로 제작한 학습 자료 모음입니다.
한국인 학습자의 눈높이에 맞추어 한국어 해설과 함께 인포그래픽 형태로
정리했으며, 모든 자료는 웹 페이지로 바로 열람할 수 있습니다.

**열람 주소: https://statepark62.github.io/japanese/**

## 콘텐츠 구성

- **문법 인포그래픽 시리즈**: 헷갈리기 쉬운 문법 항목을 시각 자료로 정리
  (예: 조건 표현 と・ば・たら・なら 비교 등)
- **표현·어휘 학습 카드**: 주제별 표현을 카드 형식으로 제작하여
  네이버 카페와 연계해 공유
- **자매 콘텐츠 — 天声人語로 배우는 일본어**: 아사히신문 칼럼을 매일
  자동 요약·발행하는 일일 학습 페이지
  → https://statepark62.github.io/tenseijingo/

## 자료의 특징

- 한국어 해설 중심: 문법 용어를 한국어 학습자 관점에서 풀어 설명
- 인쇄·공유 친화적: 화면 열람과 이미지 저장 모두를 고려한 레이아웃
- 지속 확장: 새 주제가 계속 추가되며, 목록은 위 열람 주소에서 확인

## 함께 공부하기

학습 질문과 자료 나눔은 네이버 카페에서 함께하고 있습니다.

- 네이버 카페 「여행하며 일본어 공부하기」: https://cafe.naver.com/statepark62
