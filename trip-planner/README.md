# 여행 전광판 (지금 여기) — 일반 사용자용

날짜·시간별 여행 일정을 입력해 두면, **지금 이 순간 무엇을 하기로 했는지** 큰 글씨로 보여 주는 여행 일정 웹앱입니다.
서버 없이 GitHub Pages로 제공되며, 일정은 **내 Google 시트** 또는 **내 브라우저**에만 저장됩니다.

- 앱: https://statepark62.github.io/trip-planner/
- 사용설명서: https://statepark62.github.io/trip-planner/guide.html
- 개인정보처리방침: https://statepark62.github.io/trip-planner/privacy.html
- 개발자용(제작자 전용) 설명: `README-dev.md`

## 주요 기능

| 기능 | 설명 |
|---|---|
| 실시간 전광판 | 현재 시각 기준 “지금 할 일 / 다음 할 일”을 자동 표시 |
| 날짜별 일정 관리 | 여행 기간을 날짜 탭으로 나눠 일정(시간·할 일·장소·메모) 추가·수정·삭제 |
| **일정 사진(1장)** | 일정마다 사진 1장을 붙이면 작은 썸네일로 표시, 누르면 확대 |
| 아침 일정 확인 | 앱을 열면 오늘 일정을 모아서 보여 주는 팝업 |
| 브라우저 알림 | 일정 시작 10분 전 알림(탭이 열려 있는 동안) |
| Google 시트 저장 | 구글 로그인 시 **내 드라이브의 시트**에 자동 저장·동기화 |
| 로컬 저장 | 로그인하지 않아도 이 기기 브라우저에 저장 |
| 지난 여행 목록 | 끝난 여행은 목록에서 다시 열람 |
| **일행에게 공유(읽기 전용)** | 링크 하나로 로그인 없이 일정 열람. 최신 내용은 “새로고침” 버튼으로 갱신 |
| **내보내기(PDF/JSON)** | “📤 내보내기”에서 PDF(보기·인쇄용) 또는 JSON 파일(다시 불러오기용) 선택 |
| **파일에서 불러오기** | 저장한 JSON 파일을 새 여행으로 추가(사진 포함) |
| 20개 언어 | 지구본 아이콘에서 언어 선택(아랍어는 오른쪽→왼쪽 표시) |
| 설치형(PWA) | 홈 화면에 추가해 앱처럼 실행, Android는 Google Play 출시 준비 중 |

> 새로 추가한 일부 문구(사진·내보내기·불러오기)는 한국어·영어만 번역되어 있고, 나머지 언어에서는 영어로 표시됩니다.

## 사용 방법 (요약)

1. 앱을 열고 **“+ 새 여행”**에서 이름과 기간을 입력합니다.
2. 날짜 탭에서 **“+ 일정 추가”**로 시간·할 일·장소·메모(선택)·사진(선택)을 입력합니다.
3. 여러 기기에서 쓰거나 일행과 공유하려면 **“구글 연결”**로 로그인합니다.
4. **“일행에게 공유”**를 누르면 읽기 전용 링크가 만들어집니다.
5. **“📤 내보내기”**로 PDF 또는 JSON 파일로 저장할 수 있습니다.
6. 다른 기기에서는 **“📂 파일에서 불러오기”**로 JSON 파일을 열면 됩니다.

자세한 화면 설명은 [사용설명서](https://statepark62.github.io/trip-planner/guide.html)를 참고하세요.

### 휴대폰에 설치
- **Android(Chrome):** 메뉴 → “홈 화면에 추가” 또는 “앱 설치”
- **iPhone(Safari):** 공유 버튼 → “홈 화면에 추가”

## 일정 사진

- 일정 1개당 **사진 1장**입니다.
- 고른 사진은 브라우저에서 **긴 변 320px 이하의 작은 JPEG**로 줄여 저장합니다. 원본은 저장하지 않습니다.
- 줄이는 과정에서 사진에 들어 있던 위치(GPS) 같은 숨은 정보는 남지 않습니다.
- 구글에 연결했다면 시트의 `photos` 탭에 저장됩니다. 연결하지 않았다면 이 기기 브라우저에 저장되며 용량이 작아 사진 수가 제한될 수 있습니다.
- 여행별 표(사람이 읽는 시트 탭)에는 사진이 표시되지 않고 앱에서만 보입니다.

## 일행에게 공유 (읽기 전용)

1. 구글에 연결한 상태에서 **“일행에게 공유”**를 누릅니다.
2. 앱이 해당 시트를 **“링크가 있는 모든 사용자 – 뷰어”**로 바꾸고 `?share=…` 링크를 만듭니다.
3. 링크를 받은 사람은 로그인 없이 일정과 사진을 **읽기만** 할 수 있습니다.
4. 일정이 바뀌어도 자동으로 갱신되지 않습니다. 받은 사람이 **“↻ 새로고침”**을 눌러야 최신 내용이 보입니다.
5. 공유 화면에서도 **“📤 내보내기”**로 PDF/JSON 저장이 가능합니다.

주의: 링크를 아는 사람은 누구나 볼 수 있으므로 비밀번호·결제 정보를 메모에 적지 마세요. 공유를 끊으려면 Google 드라이브에서 해당 시트의 공유를 “제한됨”으로 바꾸세요.

## 내보내기·불러오기 파일 형식(JSON)

```json
{
  "format": "trip-board",
  "version": 1,
  "exportedAt": "2026-11-17T06:30:00.000Z",
  "trip": {
    "title": "가고시마 탐방",
    "startDate": "2026-11-12",
    "endDate": "2026-11-15",
    "days": {
      "2026-11-12": [
        { "time": "10:00", "endTime": null, "title": "공항 도착", "location": "가고시마공항", "note": "", "photo": "data:image/jpeg;base64,..." }
      ]
    }
  }
}
```

- 불러올 때 파일을 **실행하지 않고 글자로 읽어** 형식만 검사합니다. 형식이 아니면 거절합니다.
- 파일 크기는 8MB 이하입니다. 불러온 여행은 원본 시트와 연결되지 않은 **복사본**입니다.
- 예전에 `.js`로 저장한 파일(`window.TRIP_DATA = …`)도 읽을 수 있으나, 새로 저장할 때는 `.json`만 만들어집니다.

## 개인정보와 권한

- 개발자가 운영하는 서버·DB가 **없습니다.** 개발자는 사용자의 일정을 볼 수 없습니다.
- 구글 로그인 권한은 `drive.file` **한 가지**입니다(이 앱이 만든 파일만 접근, 다른 Drive 파일·Gmail·연락처 접근 불가).
- 이름·이메일·프로필 사진은 읽거나 저장하지 않습니다. 광고·분석 도구가 없습니다.
- AI(PDF·사진 인식) 기능은 **일반용에 없으며**, 일반 사용자의 데이터는 AI 서비스로 전송되지 않습니다.
- 자세한 내용은 [개인정보처리방침](https://statepark62.github.io/trip-planner/privacy.html)을 참고하세요.

데이터 삭제: Google 드라이브에서 “지금여기_여행일정_데이터” 시트를 삭제하면 클라우드 저장분이 모두 사라집니다. 권한 철회는 [Google 계정 권한 설정](https://myaccount.google.com/permissions)에서 할 수 있습니다.

## 알려진 제한 사항

- 브라우저 알림은 탭이 열려 있는 동안만 동작합니다(서버 푸시 아님).
- iOS는 위치 기반 도착 알림을 지원하지 않습니다.
- 구글에 연결하지 않으면 데이터는 기기·브라우저 단위로만 저장되어 기기 간 동기화가 되지 않습니다.
- 공유 링크는 읽기 전용이며, 공유한 시트는 링크를 아는 누구나 열람할 수 있습니다.
- 두 사람이 같은 여행을 동시에 수정하는 **공동 편집은 지원하지 않습니다.** 마지막에 저장한 내용이 남습니다.
- 사진은 썸네일 수준(원본 화질 아님)이며 일정당 1장입니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 새로고침마다 다시 로그인하라고 함 | 같은 브라우저 탭에서 열었는지, 시크릿 창이 아닌지 확인 |
| “이 앱은 확인되지 않았습니다”/로그인 거부 | 앱의 OAuth 게시 상태 확인(개발자) |
| 저장이 오래 걸리는 느낌 | 화면은 먼저 바뀌고 저장은 뒤에서 진행됩니다. 하단 “☁ 저장 중…”이 사라질 때까지 탭을 닫지 마세요 |
| 공유 링크가 열리지 않음 | 링크 전체를 그대로 열었는지, 시트 공유가 “제한됨”으로 바뀌지 않았는지 확인 |
| 공유 화면 내용이 옛날 것 | “↻ 새로고침” 버튼을 누르세요 |
| 배포 후 화면이 그대로 | 강력 새로고침(Ctrl+Shift+R). iPhone은 설정 → Safari → 방문 기록 및 웹사이트 데이터 지우기 |

## 개발자 정보 (배포·설정)

### 파일 구성

| 파일 | 용도 |
|---|---|
| `trip-planner-public.html` | 일반용 앱 전체 소스 → `trip-planner/index.html`로 배포 |
| `manifest.json`, `service-worker.js`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | PWA 구성 |
| `guide.html`, `guide/*.png` | 사용설명서(한국어, 일반용에만 연결) |
| `privacy.html` | 개인정보처리방침(OAuth 게시·Play 등록에 필요) |

### 설정 (한 번만)

1. **Google Cloud Console** 프로젝트 생성 → **Google Sheets API**, **Google Drive API** 사용 설정
2. **OAuth 동의 화면**: 외부, 범위는 `drive.file`만, 홈페이지·개인정보처리방침 URL 입력 후 **프로덕션으로 게시**
3. **OAuth 클라이언트 ID(웹)**: 승인된 원본 `https://<사용자명>.github.io`, 리디렉션 URI `https://<사용자명>.github.io/trip-planner/` → 코드의 `GOOGLE_CLIENT_ID`에 반영
4. **API 키(공유 보기용)**: API 제한 = Google Sheets API만, 웹사이트 제한 = `<사용자명>.github.io/*`(경로 없이 도메인 단위) → 코드의 `GOOGLE_API_KEY`에 반영
5. 저장소를 Public으로 두고 GitHub Pages로 배포 후 강력 새로고침으로 확인

### Android(Google Play)

- [PWABuilder](https://www.pwabuilder.com)로 TWA(`.aab`) 패키징, 패키지 ID `io.github.statepark62.twa`
- 신규 개인 개발자 계정은 프로덕션 공개 전 **비공개 테스트 12명·14일** 필요(정책은 변경될 수 있으니 출시 시점에 확인)
- 주소창 없이 열리려면 `https://<사용자명>.github.io/.well-known/assetlinks.json`(도메인 루트)에 앱 서명 키 지문을 게시
- 서명 키(keystore)와 비밀번호는 반드시 백업

### 수정할 때 주의

- `trip-planner-public.html`과 개발자용 `trip-live-planner.html`은 **같은 핵심 코드**를 씁니다. 기능을 고치면 양쪽에 같이 반영하세요(AI 인식·소유자 잠금 제외).
- 배포 후 캐시 때문에 옛 화면이 보일 수 있으니 서비스 워커 캐시 버전을 올리거나 강력 새로고침을 하세요.
