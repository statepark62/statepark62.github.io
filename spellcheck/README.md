# 번역문 맞춤법 도우미

일본어를 한국어로 번역한 원고의 맞춤법을 점검하고, 어떤 규정에 따라 고쳤는지 정리해 주는 웹 도구입니다. 번역 모임 회원들이 발표 전에 원고를 점검하는 용도로 만들었습니다.

- 사용 화면: https://statepark62.github.io/spellcheck/
- 사용 안내: https://statepark62.github.io/spellcheck/guide.html

## 주요 기능

- **무료 검사**: 구글 시트에 저장한 규칙(약 1,580개)으로 자주 틀리는 표현을 찾아 고칩니다. 비용이 들지 않습니다.
- **AI 정밀 검사**: 문맥까지 살펴 고칩니다. **Gemini(무료 등급)**와 **Claude(유료)** 두 버튼이 있고, 하루 사용 횟수를 각각 제한하며 남은 횟수를 화면에 표시합니다.
- **결과 표시**: 원문과 수정문을 나란히 보여 주고, 고친 곳마다 구분·적용 규정·이유를 표로 정리합니다.
  - 빨강: 틀린 원래 표현 / 초록: 고친 표현 / 노랑: 검토 권장(틀린 말은 아니지만 다듬으면 좋은 표현)
- **저장**: 검사 결과를 HTML 파일이나 PDF로 저장합니다.
- **의견 게시판**: 글은 누구나 읽을 수 있고, 글쓰기는 접속 코드를 넣은 회원만 할 수 있습니다. 새 글은 관리자에게 메일로 알리고, 관리자가 시트에 쓴 답변이 화면에 함께 표시됩니다. 자기 글은 지울 수 있습니다(시트에서는 숨김 처리).
- **접속·검사 기록**: 접속은 '접속기록' 탭에(같은 환경은 하루 한 번), 검사 사용은 '검사기록' 탭에 따로 남깁니다. 원고 내용은 저장하지 않습니다.
- **규칙 키우기**: AI 정밀 검사에서 찾은 새 오류를 '제안' 시트에 모아 두고, 관리자가 승인하면 무료 검사 규칙으로 옮깁니다.

## 구성

```
GitHub Pages (화면)                     Google Apps Script (서버)            Google 시트 (데이터)
index.html  ── 검사·의견·접속 요청 ──▶  Code.gs  ──────────────────────▶  규칙 / 제안 / 게시판 / 접속기록 / 검사기록
guide.html                               Seed.gs (기본 규칙 목록)
                                           └─ AI 정밀 검사 시 ──▶ Gemini API / Claude API
```

| 파일 | 위치 | 설명 |

| `guide.html` | GitHub | 회원용 사용 안내 페이지 |

## 설치 순서

### 1. 구글 시트와 Apps Script

1. 새 구글 시트를 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `Code.gs`와 `Seed.gs`를 붙여넣고 저장합니다. 파일은 이 두 개만 있어야 합니다.
3. 시트를 새로고침하고 **맞춤법 도우미 → 1. 시트 초기 설정**을 실행합니다.
4. 편집기에서 `testNotify` 함수를 한 번 실행해 메일 권한을 승인합니다.

### 2. 스크립트 속성 (프로젝트 설정 → 스크립트 속성)

| 이름 | 필수 | 설명 |
|---|---|---|
| `ACCESS_CODE` | 권장 | 회원 공용 접속 코드. 비워 두면 주소를 아는 누구나 쓸 수 있습니다. |
| `ANTHROPIC_API_KEY` | AI 검사 시 | Anthropic API 키. 없으면 무료 검사만 작동합니다. |
| `DAILY_LIMIT` | 선택 | 하루 Claude 검사 한도 (기본 50) |
| `GEMINI_API_KEY` | Gemini 검사 시 | Google AI Studio에서 발급한 Gemini API 키 |
| `GEMINI_DAILY_LIMIT` | 선택 | 하루 Gemini 검사 한도 (기본 20). AI Studio에서 확인한 무료 한도보다 낮게 두세요. |
| `GEMINI_MODEL` | 선택 | Gemini 모델 이름 (기본 `gemini-flash-latest`) |
| `NOTIFY_EMAIL` | 선택 | 게시판 새 글 알림을 받을 주소 (기본: 배포한 계정) |
| `BOARD_PUBLIC_READ` | 선택 | `N`이면 게시판 읽기에도 접속 코드가 필요함 (기본: 누구나 읽기 가능, 글쓰기는 항상 코드 필요) |

API 키와 접속 코드는 이 저장소에 올리지 마세요.

### 3. 웹 앱 배포

1. **배포 → 새 배포 → 유형: 웹 앱**을 고릅니다.
2. 실행 계정은 **나**, 액세스 권한은 **모든 사용자**로 설정합니다.
3. 나온 `…/exec` 주소를 `index.html`의 `API_URL`에 넣습니다.

### 4. GitHub Pages

1. 화면 파일(`index.html`, `guide.html`, 아이콘, `manifest.webmanifest`)을 저장소 맨 위에 올립니다.
2. **Settings → Pages**에서 `main` 브랜치의 `/(root)`를 지정합니다.

## 시트 구성

| 탭 | 열 | 용도 |
|---|---|---|
| 규칙 | 사용(O/X), 틀린 표현, 올바른 표현, 구분, 규정, 이유 | 무료 검사 규칙 |
| 제안 | 일시, 틀린 표현, 올바른 표현, 구분, 규정, 이유, 상태 | AI 검사에서 찾은 규칙 후보 |
| 게시판 | 번호, 일시, 작성 기기, 내용, 관리자 답변, 답변 일시, 공개(O/X), 기기 번호 | 의견 게시판. '관리자 답변' 칸에 쓰면 화면에 표시, '공개'를 X로 바꾸면 숨김 |
| 접속기록 | 일시, 기기명, 결과, 기기, 운영체제, 브라우저, 시간대, 언어, 화면 크기, 들어온 경로 | 페이지 접속 (같은 환경은 하루 한 번) |
| 검사기록 | 일시, 기기명, 검사 종류, 글자 수, 결과, 기기, 운영체제, 브라우저 | 무료·AI 검사 사용 기록 (원고 내용은 저장하지 않음) |
| 기기별 현황 | (수식으로 자동 집계) | 기기명별 무료·AI 검사 횟수 |

**기기명**은 브라우저가 알려 주는 모델명(안드로이드 크롬 등에서만 제공)이나 기기 종류에, 브라우저마다 처음 접속할 때 만든 익명 번호를 붙인 것입니다. 예: `SM-S918N · 기기-3F2A`, `iPhone · 기기-7B10`, `Windows PC · 기기-91C0`. 같은 회원도 기기나 브라우저가 다르면 기기명이 다르고, 브라우저 기록을 지우면 번호가 새로 생깁니다.

`규칙`과 `제안` 탭의 이름은 바꾸지 마세요. 코드가 이 이름으로 찾습니다.

### 규칙 작성 방법

- **사용**: `X`로 바꾸면 그 규칙이 꺼집니다.
- **틀린 표현 앞의 `^`**: 단어 첫머리에서만 찾습니다. 예를 들어 `^력사`는 "력사"를 고치지만 "협력사"는 건드리지 않습니다.
- **올바른 표현을 비워 두면**: 고치지 않고 '검토 권장'으로만 표시합니다. 번역투나 일본어 투 용어처럼 문맥에 따라 판단할 말에 씁니다.
- **틀린 표현과 올바른 표현을 똑같이 적으면 '예외' 규칙**입니다. 예: `황벽나무 | 황벽나무 | 예외 (고치지 않음)`. 그 말은 무료 검사의 다른 규칙도, AI 정밀 검사도 고치지 않습니다(띄어쓰기 포함).
- 규칙은 글자 그대로 찾아 바꾸므로, 다른 단어의 일부와 겹치는 짧은 표현은 넣지 마세요.

## 시트 메뉴 (맞춤법 도우미)

| 메뉴 | 하는 일 |
|---|---|
| 1. 시트 초기 설정 | 처음 한 번. 탭을 만들고 기본 규칙을 넣습니다. |
| 2. 승인된 제안을 규칙으로 옮기기 | `제안` 탭에서 상태가 '승인'인 행을 `규칙`으로 옮깁니다. |
| 3. 규칙 캐시 비우기 | 시트에서 규칙을 고친 뒤 바로 반영하고 싶을 때 실행합니다. (그냥 두어도 5분 안에 반영) |
| 4. 새 기본 규칙 추가 | `Seed.gs`에 새로 생긴 규칙만 추가합니다. 기존 규칙과 O/X 설정은 그대로 둡니다. |
| 5. 기본 규칙의 규정·이유 칸 최신화 | 기본 규칙의 구분·규정·이유 칸을 `Seed.gs` 내용으로 바꿉니다. |

## 고칠 때 주의할 점

- `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 해야 반영됩니다. '새 배포'를 만들면 주소가 바뀝니다.
- `Seed.gs`만 바꿨을 때는 다시 배포할 필요 없이 메뉴 4·5·3번을 실행하면 됩니다.
- `index.html`을 바꾼 뒤에는 브라우저에서 Ctrl+F5로 새로고침하세요.

## 비용

- GitHub Pages, Apps Script, 구글 시트, 무료 검사는 비용이 들지 않습니다.
- Gemini 검사는 무료 등급 한도 안에서 비용이 들지 않습니다. 다만 무료 등급 요청은 구글 제품 개선에 쓰일 수 있습니다.
- Claude 검사는 Claude API 사용량만큼 과금됩니다. A4 2장 원고 1회에 대략 100~200원 수준입니다. Anthropic 콘솔에서 월 사용 한도를 설정해 두길 권합니다.
