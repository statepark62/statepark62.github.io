# 史 한국사 스터디 (PWA)

한국사능력검정시험 대비용 오프라인 학습 앱. 문제풀이 · 암기카드 · 오답노트 · 학습 통계 4개 탭으로 구성되어 있습니다.

## 1. 지금 바로 확인하기
`index.html`을 더블클릭해 브라우저로 열면 로컬에서도 바로 동작합니다. 다만 오프라인 설치(홈 화면 추가)와 서비스워커 캐싱은 **https로 실제 호스팅했을 때만** 정상 동작합니다(브라우저 보안 정책).

## 2. GitHub Pages로 배포하기 (추천)
기존에 쓰시던 `statepark62.github.io` 저장소의 하위 폴더로 넣는 방식입니다.

1. `statepark62.github.io` 저장소를 로컬에 클론합니다.
2. 이 폴더 전체(`hangeuksa-app`)를 저장소 루트에 원하는 이름으로 복사합니다. 예: `hangeuksa/`
3. `git add . && git commit -m "add 한국사 스터디 앱" && git push`
4. 몇 분 후 `https://statepark62.github.io/hangeuksa/` 로 접속하면 서비스됩니다.
5. 스마트폰 브라우저로 접속 후 "홈 화면에 추가"를 누르면 앱 아이콘처럼 설치됩니다.

> 별도 저장소로 배포하고 싶다면 새 GitHub 저장소를 만들고 Settings → Pages에서 배포 브랜치를 지정하면 됩니다.

## 3. 문제를 구글시트로 관리하기 (선택, 강력 추천)
문제를 코드 수정 없이 시트에서 추가·수정하고 싶다면:

1. `gas/Code.gs`의 안내(파일 상단 주석)를 따라 Google Sheet + Apps Script를 구성합니다.
2. 웹 앱으로 배포해 `/exec` URL을 받습니다.
3. 앱 우측 상단 ⚙(설정) → "문제 데이터 URL"에 그 주소를 입력하고 저장합니다.
4. 이후 시트에 문제를 추가하면 앱에서 "지금 동기화"를 누르거나 재접속 시 자동 반영됩니다.

시트가 연결되지 않은 동안은 `data/questions.json`(선사시대~현대 40문제 + 암기카드 20개 샘플)이 기본으로 사용됩니다. 실제 기출문제는 국사편찬위원회 한국사능력검정시험 홈페이지(historyexam.go.kr)의 기출문제를 참고해 시트에 채워 넣으시면 됩니다.

## 4. 데이터 구조 요약
- `data/questions.json`
  - `questions[]`: `id, era, category, q, choices[4], answer(0-based), explanation`
  - `flashcards[]`: `id, era, term, def`
- 앱은 최초 접속 시 이 데이터를 IndexedDB에 저장해두므로, 이후에는 인터넷 연결 없이도 문제풀이·오답노트·통계가 모두 동작합니다.

## 5. 학습 로직
- **가중치 랜덤 출제**: 틀린 문제일수록, 아직 안 푼 문제일수록 더 자주 나오고, 연속 2번 맞힌 문제(마스터 판정)는 노출 빈도가 낮아집니다.
- **오답노트**: 오답이 발생하면 자동 등록되고, 같은 문제를 연속 2번 맞히면 목록에서 빠집니다(마스터 표시 점 2개).
- **통계**: 누적 풀이 수, 정답률, 연속 정답, 시대별 정답률을 확인할 수 있습니다.
- **D-day**: 설정에서 시험일을 입력하면 상단에 남은 일수가 표시됩니다.

## 6. 아이콘 교체
`icon-192.png`, `icon-512.png`, `apple-touch-icon.png`을 원하는 이미지로 교체하면 홈 화면 아이콘이 바뀝니다.

## 7. 참고 — 미리보기와 실제 배포의 차이
이 앱은 브라우저의 IndexedDB에 학습 기록을 저장합니다. 채팅 내 미리보기 화면(샌드박스)에서는 저장이 되지 않거나 초기화될 수 있으니, 실제 학습은 반드시 2번 항목대로 GitHub Pages 등에 배포한 뒤 그 주소로 접속해서 사용해주세요.
