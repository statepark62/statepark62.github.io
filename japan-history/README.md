# 일본사 학습 트리

한국의 일반 독자에게 일본을 소개하는 책을 쓰기 위해 만든 **일본사 학습·정리용 웹 페이지**입니다.
일본사를 12개 시대로 나누고, 시대를 누르면 공부할 항목이 나옵니다. 항목마다 **한국과의 연결**, **답사 장소**, **참고문헌**, **집필 후보 표시와 메모**가 들어 있습니다.

서버 없이 동작하는 정적 페이지이므로 GitHub Pages에 그대로 올려서 쓸 수 있습니다.

## 바로 열기

- GitHub Pages: `https://statepark62.github.io/japan-history/`
- 내 컴퓨터: 폴더째 내려받은 뒤 본체 HTML 파일(`index.html` 또는 `japan-history.html`)을 브라우저로 엽니다.

지도는 인터넷 연결이 필요합니다. 연결이 없으면 지도 대신 구글 지도 링크가 나옵니다.

## 파일 구성

```
japan-history/
  index.html                      페이지 본체 (japan-history.html로 두어도 동작)
  japan-history-data.js           시대·항목·참고문헌·주제 목록
  japan-history-places.js         장소(지도)와 항목-장소 연결
  japan-history-chronology.js     천황·쇼군·한국 왕 연표 데이터
  japan-history-materials.js      자료실 메타데이터(분류·연결 정보)
  manifest.webmanifest            홈 화면 설치용 설정
  icons/                          탭·홈 화면 아이콘
  materials/                      자료실에 올린 문서
    material.css                  정리한 자료 3종이 함께 쓰는 서식
    tojin-tofu-history-v3.html
    saigo-two-statues.html
    shimazu-joseon-potters.html
    okubo-toshimichi.html
    img/                          자료에 쓴 사진·그림과 원본 인포그래픽
  README.md
```

모든 `.js` 파일과 `materials/` 폴더는 본체 HTML과 같은 폴더에 있어야 합니다.

## 화면 구성

| 탭 | 내용 |
|---|---|
| 시대별 보기 | 12개 시대 트리. 시대를 누르면 정치·사회 / 대외·한국 관계 / 문화·생활 항목이 나옵니다. |
| 한국 관련 모아보기 | 한국과의 연결이 적힌 항목을 시대 순으로 모읍니다. |
| 주제별 보기 | 13개 주제(천황과 왕권, 무사와 막부, 음식, 현대 사회 등)로 시대를 가로질러 모읍니다. |
| 집필 후보 모아보기 | 항목에서 ‘책에서 다룰 후보’로 체크한 것만 모읍니다. |
| 지도 보기 | 항목에 연결된 장소를 지도에 표시합니다. 빨간 점은 한국·중국, 파란 점은 일본입니다. |
| 연표 | 천황·쇼군·한국 왕을 세 줄로 나란히 보여 줍니다. 연도를 입력하면 그때 재위한 인물을 찾아 줍니다. |
| 자료실 | 올린 자료를 종류·주제·시대·상태로 분류해 보관합니다. 시대 항목과 서로 연결됩니다. |

**돌아가기:** 탭·시대 노드를 누르거나 자료실의 ‘연결된 항목’ 같은 링크로 화면이 바뀌면 내용 위쪽(스크롤해도 따라옴)에 작은 ‘← 돌아가기’ 버튼이 나타나고, 눌러서 이전 화면(탭·필터·펼침 상태·스크롤 위치)으로 돌아갑니다. 브라우저의 뒤로가기나 휴대폰의 뒤로가기 제스처도 같은 동작을 합니다. 자료실의 자료 문서는 새 탭에서 열리며, 새로 만든 자료 문서에는 맨 위에 ‘일본사 학습 트리로 돌아가기’ 링크가 있습니다.

## 12개 시대

1. 선사(조몬·야요이) 2. 고분·야마토 3. 아스카 4. 나라 5. 헤이안 6. 가마쿠라
7. 무로마치·센고쿠 8. 아즈치모모야마 9. 에도 10. 메이지 11. 다이쇼·쇼와 전기 12. 전후·헤이세이·레이와

## 항목의 구조

`japan-history-data.js`의 `window.ERAS` 안에 시대별로 들어 있습니다.

| 필드 | 설명 |
|---|---|
| `id` | `e<시대번호>-<번호>` 형식(예: `e8-12`). 한 번 정하면 바꾸지 않습니다. |
| `title`, `year` | 제목과 시기 |
| `summary` | 핵심 내용 |
| `korea` | 한국과의 연결. 없으면 빈 문자열 |
| `site` | 답사 장소 설명 |
| `refs` | 참고문헌 키 목록(`window.REFS`에 정의) |
| `note` | 확인이 필요한 사항. 비어 있지 않으면 화면에 ‘⚠ 원문 확인 필요’가 표시됩니다. |
| `themes` | 주제 꼬리표(`window.THEMES`에 있는 값) |

## 새 항목을 추가하려면

1. `japan-history-data.js`에서 해당 시대의 알맞은 주제 묶음(`topics`)에 항목을 추가합니다. `id`는 그 시대의 마지막 번호 다음 번호를 씁니다.
2. 새 참고문헌은 `window.REFS`에 키와 서지를 추가하고 `refs`에 키를 적습니다.
3. 새 장소는 `japan-history-places.js`의 `window.PLACES`에 추가하고, `window.ITEM_PLACES`에서 항목 `id`와 연결합니다. 위치가 대략적이면 `a:1`, 한국·중국이면 `k:1`을 붙입니다.
4. 브라우저에서 열어 항목이 보이는지, 개발자 도구 콘솔에 오류가 없는지 확인합니다.

## 새 자료를 올리려면

1. 원본 문서를 수정하지 않고 `materials/`에 넣습니다.
2. `japan-history-materials.js`의 `window.MATERIALS`에 항목을 추가합니다.
   - `kind`(종류), `themes`(주제), `eras`(시대), `korea`(한국 관련), `status`(상태), `source`(출처 유형)
   - `items`(연결할 항목 `id`), `places`(장소 키), `chapter`(책 장 후보), `caveats`(확인 필요 목록)
3. 시대에 앉힐 수 있는 사건·제도·인물은 따로 시대 항목으로 만들고, 사례 연구·답사·긴 해설은 자료로만 둡니다.

## 자료 신뢰도에 관한 원칙

- 확인한 사실과 전승·추정을 구분해 적고, 확신이 없으면 `note`에 남겨 화면에 ⚠로 표시합니다.
- 양국 입장이 갈리는 주제(독도, 청구권, 야스쿠니, 강제동원 등)는 한국과 일본의 입장을 나란히 적고 근거를 병기합니다.
- 숫자는 출처별로 따로 적습니다. 통계(출생아 수, 고령화율, 미군 기지 비율 등)는 매년 바뀌므로 출판 직전에 원자료로 바꿉니다.
- 위키백과는 보조 자료로만 쓰며 참고문헌에 ‘보조 자료’로 표시합니다.
- 서지와 연도는 일부가 기억에 근거하므로 **출판 전에 원문과 대조해야 합니다.** 이 페이지는 공부와 집필 준비용 자료이며 인용의 최종 근거가 아닙니다.

## 알려진 한계

- 지도 타일(Esri)이 보이지 않으면 항목 카드의 구글 지도 링크를 이용하세요. 장소 좌표는 일부가 대략적 위치입니다(`a:1`).
- 후보 체크와 메모는 **브라우저에 저장**됩니다. 주소(파일로 열기 / GitHub Pages)나 기기가 다르면 저장소가 달라져 서로 보이지 않습니다. 기기 간 동기화는 구글 시트 연동(예정)으로 해결할 계획입니다.
- 연표의 초기 천황(제1~14대)은 전승, 제15~28대는 연대 논쟁이 있습니다. 삼국 초기와 금관가야 연대도 전승 기년입니다.
